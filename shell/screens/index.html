Адрес сервера Квазара

Для сотрудников: адрес компьютера с Квазаром, например http://192.168.1.10:8080. Для облака — адрес вида https://компания.kvazar.ru

По этому адресу отвечает не Квазар. Если вы уверены, что адрес верный (например, нестандартный прокси), можно продолжить всё равно.

Сервер ещё поднимается? «Сохранить без проверки» — оболочка будет пытаться подключиться сама.
