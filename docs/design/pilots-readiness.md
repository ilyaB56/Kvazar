### 1.2 Блокеры аналитика (до пилотов, потеря актива иначе)
- **Д6 race**: конкурентное проведение двух отгрузок может продать
  один остаток/код дважды → SELECT FOR UPDATE по балансовой строке
  item×location и кандидатам-серийникам; тест на конкурентный пост.
- **Д7 FIFO-фиксация + П10**: выданные коды фиксируются при проведении;
  **в shipment_lines хранить serial_ids (ссылки на item_serials), НЕ
  открытые коды** (правка ревью sales-automation §12.5); расшифровка
  выданных кодов в API — только rw. COGS серийных = unit_cost
  конкретного кода (решение основателя 2026-09-10).
- **Д13 void/брак кода**: команда «испортить код» = движение
  «Цифровой склад → Брак» + status=void; исключить is_transit-локации
  из правила kind-совместимости (П9 — цифровой товар в транзит Брак).
- **П10 себестоимость выдачи цифровых — РЕШЕНО основателем
  2026-09-10: по рекомендации архитектора — unit_cost конкретного
  выданного кода** (точная маржа партии; для qty-товаров остаётся
  средняя). Реализуется вместе с Д7: фиксация выданных кодов даёт и
  точный COGS.

## Этап 2 — мини-заезд «месяц жизни компании» (после гейта)
Отдельный стенд; генерация живых демо-данных (закупки/продажи/сборка/
цифровые коды/оплаты за месяц). Проверка по чеклисту QA (20 инвариантов:
двойная запись, Σ value = Σ qty × avg, маржа в трёх срезах, касса,
категории, заморозка курса, сторно-пары, номера без дыр, периоды, права,
серийники, отклик <2с, outbox, резервы, бэкап-restore) — чеклист в
отчёте QA (архитектурный чат передаст текстом). Двойная цель:
стабильность под объёмом + демо-данные с копейками.

## Этап 3 — демо-пакет
- Сценарий показа ≤45 мин: вход → роли (матрица) → сделка CRM → заказ
  клиента → отгрузка (и выдача цифрового кода) → оплата → дашборд с
  маржой → отчёты → интеграции (ядро) → ассистент.
- Чистый стенд с демо-данными ≤30 мин, воспроизводимо (скрипт/дамп).
- Чистка тест-данных живой БД (pytest/smoke/qa-хвосты).

## Осознанно НЕ делаем в этом цикле
Бэклог H (палитра/канбан/командная палитра — по триггеру «пилоты
просят»), полный P1-безопасность (по триггеру «первый платный»),
возвраты/курсовые разницы и прочие «важные» дыры аналитика (Д1/Д2/Д4/
Д5/Д8–Д12 — в план второго цикла по мере пилотов).
