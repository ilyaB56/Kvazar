# Квазар — коробочная версия: руководство владельца

Эта страница — для владельца коробки Квазара: установка, ежедневная
работа, обновления, бэкапы и удаление. ИТ-специалист не нужен.

## Установка

1. Скачайте `kvazar-setup.exe` (ссылка выдаётся при покупке) и запустите.
2. Мастер сам проверит компьютер (память, место на диске, настройки
   BIOS) и при необходимости установит среду выполнения — это займёт
   10–20 минут, включая загрузку компонентов (~2–3 ГБ).
3. При появлении окна «Первая настройка» введите название организации,
   ваше имя, email и пароль администратора (не короче 8 символов,
   буквы и цифры). Этот пароль — вход администратора в Квазар.
4. Готово — браузер откроет `http://localhost:8080`, на рабочем столе
   появится ярлык «Квазар».

Требования: Windows 10 (1809+) или 11, от 6 ГБ ОЗУ (рекомендуется 8+,
с ИИ-ассистентом — 8+), 10 ГБ на диске, интернет, включённая
виртуализация в BIOS (обычно включена; мастер подскажет, если нет).

### Важный файл: .env

После установки в `Документы\Quasar\stack\.env` лежат ключи шифрования
ваших данных. **Сохраните копию этого файла на флешку или в облачный
сейф** — без него нельзя восстановить бэкапы на другом компьютере.

### Слабый компьютер (до 8 ГБ памяти)

Установщик сам создаёт файл `.wslconfig` с ограничением памяти
виртуальной машины (5 ГБ + 2 ГБ подкачка), чтобы Квазар не «съедал»
всю память. Менять его вручную не нужно. Если компьютер совсем слабый
(6 ГБ), ИИ-ассистент будет отключён — это нормально.

## Ежедневная работа

- **Вход**: ярлык «Квазар» или `http://localhost:8080` на сервере.
- **Сотрудники**: с любого компьютера в той же сети откройте
  `http://<адрес-сервера>:8080` (адрес подскажет администратор в
  Квазаре: «Система → Настройки»). Пароли выдаёт администратор.
- **Перезагрузка сервера**: ничего делать не нужно — Квазар поднимется
  сам в течение 2–3 минут после входа в Windows.

### Доступ из другой сети (удалённый офис / дом)

Рекомендуем [Tailscale](https://tailscale.com) — бесплатный для
малых команд: установите его на сервер и на ваш ноутбук, и Квазар
будет доступен по адресу `http://<tailscale-имя-сервера>:8080` из
любой точки мира без открытия портов. Альтернатива — VPN-роутер.

## Команды (меню Пуск → «Квазар» или консоль)

| Команда | Что делает |
|---|---|
| `kvazar status` | состояние, версия, здоровье всех служб |
| `kvazar update` | обновление: проверка подписи → бэкап → новые образы → проверка; при сбое — автоматический возврат на прежнюю версию |
| `kvazar backup` | ручной бэкап в `Документы\Quasar\backups\` с проверкой целостности |
| `kvazar restore "файл" --yes` | полное восстановление из бэкапа (замещает текущие данные!) |
| `kvazar stop` / `kvazar start` | остановка / запуск |

Бэкапы создаются и автоматически — каждый день в 03:00, хранятся
последние 7 (настраивается). Для спокойствия раз в неделю копируйте
свежий файл из `Документы\Quasar\backups\` на внешнее хранилище.

### Восстановление

1. `kvazar restore "C:\...\kvazar-20260926-1530.enc" --yes`
2. Перед применением команда покажет, какая организация записана
   в бэкапе и когда он создан — убедитесь, что это нужный файл.
3. Восстановление полностью замещает текущую базу данных. Отменить
   после применения нельзя — поэтому команда требует явное `--yes`.

## Гигиена диска

Квазар и среда выполнения занимают ~6 ГБ; бэкапы растут со временем
(по умолчанию хранится 7 — старые удаляются автоматически). Образы
обновлений очищаются сами. Если место кончилось — проверьте папку
`Документы\Quasar\backups\` и скопируйте старые бэкапы на внешний
диск перед удалением.

## Обновления

Квазар сам проверяет обновления раз в сутки и показывает баннер с
перечнем изменений. Применить: кнопка «Обновить сейчас» в интерфейсе
или `kvazar update`. Перед каждым обновлением автоматически создаётся
бэкап; если новая версия не проходит проверку здоровья — Квазар сам
возвращается на прежнюю версию, данные не теряются.

## Удаление

«Пуск → Квазар → Удалить» (или Параметры → Приложения). Мастер
спросит: **удалить данные?**
- **Нет** — останется база и бэкапы; повторная установка подхватит
  всё как было (например, при переустановке Windows поверх).
- **Да** — база, бэкапы и папка `Документы\Quasar` удаляются полностью.
  Сначала скопируйте бэкапы, если данные могут пригодиться!

Среда выполнения (невидимый компонент, который запускает Квазар)
не удаляется — её используют и другие программы. При желании удалите
её отдельно: «Параметры → Приложения → Docker Desktop».

## Частые вопросы

**После перезагрузки сайт не открывается.** Подождите до 3 минут —
Квазар поднимается автоматически. Проверьте: `kvazar status`.

**Забыли пароль администратора.** На экране входа — «Забыли пароль?»;
письмо со ссылкой придёт на почту, указанную при установке (если
настроена почта платформы), либо попросите платформенного
администратора сбросить пароль.

**Перенос на новый компьютер.** `kvazar backup` на старом → установите
Квазар на новом → `kvazar restore "файл" --yes` → скопируйте `.env`
из старой установки (иначе старые бэкапы не расшифруются).
