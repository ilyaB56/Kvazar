# Архитектурные решения (ADR)

Журнал принятых архитектурных решений проекта. Каждый ADR — зафиксированное
решение с обоснованием: обсуждаем в архитектурном чате, исполняем в чате
разработки. Изменить решение можно только новым ADR, а не правкой старого.

| № | Решение | Статус | Дата |
|---|---------|--------|------|
| [001](001-network-access-via-integrations.md) | Доступ к сети — только через интеграционный модуль | Принято | 2026-08-18 |
| [002](002-api-versioning.md) | Версионирование API (`/api/v1`) | Принято | 2026-08-18 |
| [003](003-money-and-multi-currency.md) | Денежные величины и мультивалютность (уровень 1) | Принято | 2026-08-20 |

Кандидаты на следующие номера: лицензирование (офлайн-ключи Ed25519),
мост `hub_link` локальная часть ↔ облачный хаб, мультитенантность SaaS.
Номер закрепляется за решением в момент его принятия.
